# account-niche-finder · 账号定位分析 Skill

一个对话式的账号定位分析技能：通过 5-6 轮结构化对话盘点你的真实素材，分析你适合用 AI 做什么类型的内容账号（聚焦小红书图文 + 公众号），输出一份包含首选方向、五维评分、验证方案的定位报告。

## 它能做什么 / 不能做什么

**能做**：把"我该做什么账号"这个无限大的问题收敛到 2-3 个最值得验证的方向，每个方向附最低成本验证方案，报告敢排序、敢裁决——包括"你现在不该开号"这种结论。

**不能做**：预判内容数据。没有人能保证你做哪个赛道能火，本 skill 的诚实边界是"收敛方向 + 最小成本验证"，不是"算出答案"。

核心方法论（详见 SKILL.md）：

- **AI 生产形式，人供给内容**——分析的主线是你有什么 AI 替代不了的素材
- **证据 > 自评**——用户对自己的评估普遍不准，行为证据永远权重更高
- **向往与素材冲突是主战场**——拆向往（桥接/转化/戳破），不选边站
- 五维评分 + 动态权重，时效敏感字段（平台政策、赛道热度）强制联网核实

## 安装

把整个目录复制到你的 agent skills 目录即可：

```bash
# ZCode / Claude Code 等 Agent Skills 格式的工具
git clone <repo-url>
cp -r account-niche-finder ~/.agents/skills/
```

依赖：宿主 agent 具备 WebSearch 能力（用于对标博主分析与时效字段核实）和 docx 生成能力（可选，用于 Word 定稿导出；不具备时 md 工作稿即为交付物）。

## 使用

新开会话，直接说：

- "我想用 AI 做个账号，不知道做什么方向，帮我分析下"
- "我想做自媒体，纠结选什么赛道"
- "我适合做什么类型的内容账号"

约 15-20 分钟、5-6 轮对话后得到报告（md 工作稿，确认后可导出 Word 定稿）。

## 免责声明

- 示例对话与示例报告中的人设为虚构，数据为演示用途。
- 平台政策、流量规则、变现门槛等时效信息以联网核实为准；本仓库的赛道地图描述可能随时间过期。
- 分析基于对话证据，不构成收益承诺。大多数账号做不起来是基础概率，本 skill 的价值是用最小成本帮你排除坏方向。
